# reMaestro — website

The marketing site for **reMaestro**, the self-hosted brain for your whole home theatre.
Served via GitHub Pages at [remaestro.app](https://remaestro.app).

Static, no build step: `index.html` + `styles.css` + `main.js`. Source of truth lives in the main
reMaestro repo under `site/`.
